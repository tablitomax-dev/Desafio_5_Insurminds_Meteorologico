# Memory Bank

Este diretório armazena contexto persistente para humanos e agentes.

## Estrutura

- `standards/`: regras técnicas e de colaboração aprovadas
- `intents/`: contexto e requisitos de problemas/features
- `bolts/`: planos e registros de execução de unidades de trabalho
- `operations/`: deploy, execução, observabilidade e incidentes

## Regras

- Não registrar segredos, tokens, dados pessoais ou informações confidenciais.
- Não inventar decisões: decisões aprovadas pertencem a `docs/decisions/`.
- Atualizações em standards exigem revisão humana.
- Cada mudança relevante deve apontar para Issue/PR e spec relacionada.
